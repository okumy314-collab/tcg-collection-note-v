# TCG Collection Note

トレーディングカードのコレクション管理と相場確認を行う、スマートフォン向けWebアプリです。

## 現在の構成

- `index.html`：アプリ本体
- `data/poke.json`：ポケモンカードのシリーズ・カードデータ
- `data/op.json`：ワンピースカードのカードデータ
- `data/ygo-oac.json`：遊戯王 ORIGINAL ARTWORK COLLECTION（YAC1）データ
- `scripts/`：データ取得・画像監査・回帰検証
- `.github/workflows/`：プレビュー公開、データ更新、品質検証

## 現在のデータ範囲（開発ブランチの検証時点）

| タイトル | データ件数 | 補足 |
|---|---:|---|
| ポケモン | 190シリーズ / 12,957カード行 | TCGdex日本語データを基礎に、直近シリーズの一部はシリーズ情報のみ登録 |
| ワンピース | 4,473カード行 | 日本語カード番号・パラレル識別子を保持。画像応答検証あり |
| 遊戯王 OAC | 100カード | YAC1-JP001〜100。レアリティ仕様は公開カードリストに基づく |

件数は更新処理により変わるため、固定の収録件数を保証するものではありません。

## 画像の扱い

- URLが存在するだけでは、正しいカード画像として扱いません。
- 画像URLの応答確認と、カード番号・絵柄・レアリティの目視確認を分けて管理します。
- YAC1の基本画像は100/100件について、ユーザーによる絵柄確認・承認が完了しています（2026-11-17）。これは基本画像の確認状況であり、公式データベース由来の画像であることや、全レアリティ版の画像が揃っていることを意味しません。
- YAC1のレアリティ仕様は346組・14表記を登録済みです。一方、レアリティ別の専用画像URLは現時点で0件です。基本レアリティと異なる版では誤画像を代用せず、専用画像がない場合は非表示にします。
- ポケモン M6a は176件。明示的な画像URLがある行は147件で、29件（105〜128、130〜134）は引き続き画像ソース調査が必要です。
- ワンピースの画像応答チェックは自動検証です。アプリ画面上の全画像を実機で目視確認したことを意味しません。
- 画像の誤表示を避けるため、未確認候補を確認済み画像へ自動昇格させません。

## アプリ機能

- タイトル・シリーズ別のカード検索と登録
- マイコレクション、所持数変更、カード詳細
- 店舗別の相場入力・比較、価格履歴表示
- カードマスターの確認と画像再取得
- コレクション・価格履歴・カードマスターのJSONバックアップ／復元
- CSV出力

### 相場機能の制限

現時点では、店舗検索リンクから価格を確認し、アプリに手入力する方式が中心です。カードショップの販売価格・買取価格を安定して自動収集する機能は未完成です。表示価格をリアルタイム価格と誤認しないよう、取得元と更新時点を確認して運用してください。

## データ更新

`fetch-poke.mjs` はTCGdexの日本語APIからポケモンのシリーズ・カードデータを取得します。`scripts/fetch-op.mjs` は公開されている日本語ワンピースカードデータを取得し、カード番号とパラレル識別子を保持します。

`.github/workflows/update-data.yml` は手動実行と週次スケジュールを設定しています。定期実行の対象ブランチや公開ブランチはGitHub Actionsの設定を確認してください。YAC1データは専用JSONと検証スクリプトで管理しています。

## 品質検証

`.github/workflows/validate-one-piece-data.yml` では、少なくとも以下を確認します。

1. アプリ・データ取得スクリプトの構文
2. バックアップ／復元と画像保護の回帰チェック
3. YAC1の番号・レアリティ・画像フォールバック
4. 検索・シリーズ選択・登録処理
5. ワンピースのカード識別子・パラレル・画像応答
6. M6aの画像URL・カードID・レアリティ
7. ポケモンとYAC1のデータ形式

自動検証合格は、iPhone実機での全画面・全カードの表示確認を意味しません。公開前にはプレビューで検索、登録、編集、画像、バックアップ復元を実機確認してください。

## 開発・公開時の注意

- 開発中の変更は開発ブランチとプレビューで検証します。
- ユーザーのローカル保存データを消す可能性があるため、サイトデータ削除やIndexedDB初期化を安易に案内しません。
- メインブランチへのマージや正式公開は、内容確認と明示的な承認後に行います。
